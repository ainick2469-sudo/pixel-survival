# Recipe Progress

## Philosophy

The game can eventually support thousands of recipes, but Session 1 deliberately focuses on schema and folder structure rather than content volume.

## Recipe bands

1. Foundational
2. Early progression
3. Mid progression
4. Specialization
5. Settlement and industry
6. Late game

## Foundational seed targets

- sticks
- fiber rope
- primitive tools
- starter blocks
- campfire
- basic storage
- basic work surface
- simple food prep
- basic backpack

## Session 1 status

- Recipe schema documented
- Recipe category folders scaffolded
- No crafting execution yet
- Content expansion begins after terrain and world feel have real shape
